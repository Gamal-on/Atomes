# ATOMES Project

## Objective and Protocol

Objective : Reconstruction of the structure factor of urea

## Simple Launch

### Prerequisites : virtual environmment

- Install `uv` : 

For MacOS and Linux users : 

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Powershell users : 

```bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```


- Clone the repository

### Installation

From the project root, run:

```bash
uv sync
```

This command creates the project environment and installs all dependencies specified in `uv.lock`.

### Running the Project

To launch the project, run:

```bash
uv run python main.py
```

This command executes `main.py` within the project's managed environment.


## Using Multiwfn

This project uses the Multiwfn software (http://sobereva.com/multiwfn/) to determine the electronic densities of the systems under consideration. The git repository does not directly call Multiwfn; instead, the text files generated by the software were manually imported.

## Code Structure

Throughout the project, data are organized in a dictionary whose keys correspond to the atoms of the molecule under study (urea in this case). Various properties are progressively associated with each atom, including atomic numbering, electronic densities, Hirshfeld weights, and other related quantities.

### Partitioning

The scripts related to this part are located in the /Partitioning folder.

The Hirshfeld weight of an atom in a molecule, as a function of position, is given by:

$\omega_j(r) = \frac{\rho_j(r)}{\rho^M(r)}$

With:

* $\rho_j(r)$ the spherical electronic density of an isolated atom
* $\rho^M(r)$ the electronic density of the promolecule

Scripts:$\\$
calcul_weights.py: computes Hirshfeld weights using the formula above
export_weights.py: exports the Hirshfeld weights to a text file
plot_weights.py: plots the Hirshfeld weights for a given atom
